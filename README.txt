NMC vs LFP Battery Chemistry Explorer — Website deployment

This is a static website. No build tools or server-side code are required.

PUBLISH WITH GITHUB PAGES
1. Sign in to GitHub and create a new PUBLIC repository, for example: nmc-lfp-explorer.
2. Upload the contents of this folder to the repository root (index.html, ru.html, nmc-lfp-github-pages.zip, and .nojekyll). Do not upload a folder containing these files as a nested directory.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose “Deploy from a branch”.
5. Select branch “main” and folder “/(root)”, then Save.
6. Wait for GitHub Pages to finish publishing. The public URL will be shown in Settings → Pages, usually https://YOUR-USERNAME.github.io/nmc-lfp-explorer/.

The English page is index.html. The Russian page is ru.html. Keep both files in the repository root so the language link works. Keep nmc-lfp-github-pages.zip in the root for the download button to work.

You must publish it from your own GitHub account; this package alone does not create a public URL.
